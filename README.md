# 怀古 (Huaigu) · 千载风流一图寻

> **足不出户，拜谒华夏历代先贤陵寝，凭吊千古名胜遗迹，与千年前的灵魂跨越时空对话。**

「怀古」是一款零第三方依赖、采用纯正宣纸水墨与传统矿物设色美学的中国历史文化数字凭吊与古今 AI 对话开源项目。收录上起上古先秦、下迄明末的 **123 位华夏先贤陵寝** 与 **38 处重大历史名胜古迹**（共 **161 处人文坐标**）。

---

## ✨ 核心特性

1. **九州水墨舆图（Albers 等积圆锥投影）**
   - 手绘水墨山川水系，支持无极滚轮缩放、拖拽漫游、双指触控与黄金角螺旋同城防重叠布局。
   - 支持 **「● 先贤陵墓 / ◆ 名胜古迹」** 图层切换，以及 **6 大历史时期 × 9 大身份/遗址类别** 双维组合筛选与「神州怀古录」实时搜索飞越。

2. **考据级历代陵寝与古迹规制生成引擎（29 种定制水墨建筑）**
   - 依据《周礼》《礼记》《后汉书·礼仪志》《唐会要》《营造法式》《大明会典》与现存古迹原型，按人物等级与古迹性质生成专属水墨建筑与礼制碑刻：
     - **帝王霸主（18人）**：秦汉覆斗方上大陵 + 子母双石阙、唐宋因山为陵 + 百级御阶华表、明代宝城宝顶 + 方城明楼、成吉思汗八白室金顶大帐；配双龙盘顶「圣旨」螭首巨碑。
     - **圣贤哲人（11人）**：曲阜孔林规制四柱三间冲天石牌坊 + 汉白玉须弥座石栏；配尖拱圭首篆额圣碑。
     - **文臣名相（19人）**：敕建重檐歇山顶「御碑亭」+ 祠垣望柱；配一品规制「螭首龟趺（赑屃驮碑）」。
     - **武将名帅（18人）**：霍去病墓式「冢象祁连山」嶙峋叠石将坛 + 神道披甲石马 + 辕门石阙与帅旗。
     - **起义豪杰（9人）**：三层花岗岩誓师盟坛 + 青铜双耳燎原火盆（动态篝火）+ 摩崖劈裂剑碑。
     - **百工奇人（24人）**：玄奘兴教寺五层唐代砖石密檐舍利塔、登封覆斗式古观星台与铜浑仪、医圣百工飞檐石龛祠。
     - **文豪艺人（24人）**：江南粉墙黛瓦月洞门 + 海棠漏窗 + 青砖罗圈诗冢 + 太湖奇石。
     - **名胜古迹（38处）**：涵盖 **14 处古战场遗址**（赤壁、长平、牧野、巨鹿、垓下、官渡、五丈原、淝水、虎牢关、睢阳、采石矶、崖山、鄱阳湖、山海关）、**12 处著名建筑与宫殿遗址**（都江堰、阿房宫、汉未央宫、邺城铜雀台、会稽兰亭、赵州桥、唐大明宫、滕王阁、黄鹤楼、岳阳楼、明紫禁城、嘉峪关）与 **12 处重大考古文明遗址**（良渚古城、二里头夏都、安阳殷墟、三星堆、秦兵马俑、马王堆汉墓、楼兰古城、云冈石窟、龙门石窟、敦煌莫高窟、交河故城、南海一号）。

3. **古树挂牌 & 石供桌敬献供品**
   - 墓旁/古迹旁程序化生成苍松、古柏、垂柳、寒梅、桃花、修竹、银杏、古樟等水墨古树，用户可手写缅怀木牌悬挂于枝头随风轻摆。
   - 碑前设传统石供桌与青铜香炉，支持敬香，并可摆放 **传统祭品**（椒浆酒、三牲、青团等）、**人间烟火**（火锅、奶茶、快乐水、红烧肉等）或 **今世信物**（中国高铁模型、月球土壤、复兴号、神舟飞船等）告慰古人。

4. **生平纪年 · 遗址考据 · 传世诗文竖排长卷**
   - 每位先贤与每处古迹均配有详实传记/遗址考略、时间轴纪年与传世代表作竖排宣纸卷轴。

5. **轻触碑石 · 跨越千年 AI 古今对话**
   - 点击墓碑或古迹石碑触发水墨晕染时空转场，进入萤火星空下的「古今对话空间」，与对应古人魂灵或「古迹千年守灵人」进行流式对话。

## 🚀 快速启动

本项目**零第三方 npm 依赖**，仅需 Node.js（建议 v18+）即可直接运行：

```bash
# 克隆仓库
git clone https://github.com/cusclo/huaigu.git
cd huaigu

# 启动服务（默认端口 5173）
npm start
```

浏览器访问：**`http://localhost:5173`**

> **关于古今对话 AI 驱动**：默认调用本机安装的 `agy` CLI 进行流式生成；若本机未安装 `agy`，系统亦内置优雅的古风降级回响，不影响任何浏览与祭扫交互。可通过环境变量 `PORT`、`AGY_BIN`、`HUAIGU_MODEL` 自定义配置。
